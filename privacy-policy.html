Политика конфиденциальности Together Dates

Последнее обновление: 4 октября 2026 года

Эта политика описывает, какие данные обрабатывает Telegram-бот Together Dates при использовании его в групповых чатах и при подключении интеграции с Pinterest.

1. Какие данные обрабатывает бот

Для работы боту может потребоваться идентификатор Telegram-группы (chat ID), дата начала отношений, часовой пояс, время уведомлений, а также добавленные администратором названия и даты ежегодных праздников.

Бот не сохраняет содержимое обычных сообщений группы, переписки пользователей, пароли Telegram или пароль Pinterest.

2. Pinterest

Если владелец проекта подключает Pinterest API, бот может получать из указанной доски Pinterest изображения и связанные с ними технические метаданные в пределах разрешений, выданных Pinterest.

Access token Pinterest хранится как секретная конфигурация приложения и не публикуется в интерфейсе бота.

3. Как используются данные

Данные используются только для работы функций бота: расчёта сроков отношений, планирования уведомлений, выбора изображений и предотвращения повторной отправки одного и того же события.

4. Хранение

Данные конфигурации хранятся в локальной базе данных экземпляра бота. Срок хранения определяется владельцем экземпляра. Данные могут быть удалены вместе с базой данных или по запросу владельца проекта.

5. Передача данных

Бот не продаёт и не передаёт данные пользователей для рекламы. При использовании Pinterest API запросы к Pinterest обрабатываются инфраструктурой Pinterest в соответствии с политиками Pinterest.

6. Удаление данных

Для удаления настроек конкретной группы достаточно удалить запись этой группы из базы данных экземпляра бота либо обратиться к владельцу проекта.

7. Контакты

По вопросам конфиденциальности и удаления данных: обратитесь к владельцу проекта через канал связи, указанный вместе с экземпляром бота.

8. Изменения политики

Политика может обновляться при изменении функциональности бота или требований используемых API. На этой странице будет указана дата последнего обновления.
